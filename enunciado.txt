Projeto: Plataforma de Serviços Locais (Marketplace de Serviços)
1. Visão Geral
Desenvolver uma plataforma web distribuída que conecte:

Prestadores de serviços (ex: eletricista, encanador, designer)

Clientes que desejam contratar serviços

A aplicação deve funcionar como um mini “Uber de serviços”, com foco em arquitetura bem estruturada e boas práticas de engenharia de software.

2. Objetivos de Aprendizagem
Aplicar:

Engenharia de requisitos

Modelagem (UML)

Arquitetura de software (cliente-servidor / camadas)

Desenvolvimento full-stack

Testes de software

Versionamento com Git

Trabalho em equipe

3. Escopo Funcional (MVP obrigatório)
Usuários
Cadastro e login

Perfis (cliente ou prestador)

Prestadores
Criar perfil com serviços oferecidos

Definir preço e descrição

Disponibilidade básica

Clientes
Buscar serviços

Visualizar perfis

Solicitar serviço

Sistema
Registro de solicitações

Status (pendente, aceito, concluído)

Avaliação simples (1–5 estrelas)

4. Requisitos Técnicos
Arquitetura cliente-servidor

API REST

Banco de dados relacional ou NoSQL

Interface web (responsiva)

Sugestões de Stack (opcional)
Backend: Node.js / Java / Python

Frontend: React / Vue / HTML + JS

Banco: PostgreSQL / MongoDB

5. Requisitos Não Funcionais
Segurança básica (login com autenticação)

Usabilidade (interface clara)

Modularidade (código organizado)

Documentação mínima obrigatória

Deploy (local ou nuvem)
